# 作品設定と制作規約

このフォルダーを、作品の画面設定と文章による制作上の取り決めの正本として扱います。

- `setting.txt`: シナリオ・素材フォルダー、開始シナリオ、作品名、再生機テーマを指定します。
- `player-ui.json`: 会話ウィンドウ、名前欄、選択肢など、再生画面の見た目を設定します。
- `game-screens.json`: タイトル、メニュー、ロード等の画面と画面遷移を定義します。
- `story-adaptation.md`: この作品固有の翻案・人物・シナリオ方針です。
- `asset-folders.txt`: 素材の分類と参照規約です。

設定画面の画像パスは作品の `asset/` を基準にします。`asset/ui/` には画面から参照する画像素材を置き、JSON設定本体はこのフォルダーに置きます。

コンパイラの生成物とビルド成果物は `.novel/` に置きます。そこにあるファイルは手編集しないでください。
