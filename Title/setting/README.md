# 作品設定フォルダー

ここには実行時に読む設定と、制作時に参照する文章を分けて置きます。UIの画面HTML/CSSの仕様は [`screens/README.md`](screens/README.md) を参照してください。

| ファイル | 用途 | 実行時に読むか |
|---|---|---|
| `setting.txt` | シナリオ／素材フォルダー、開始ファイル、作品名、再生機テーマ | 読む |
| `player-ui.json` | シナリオ再生中の会話欄、話者名、選択肢など | 読む |
| `game-screens.json` | 初期画面、画面一覧、画面HTML参照、画面全体の背景・BGM | 読む |
| `screens/*.html` | タイトル／メニュー等の要素、表示文言、動作 | `game-screens.json`から参照して読む |
| `screens/shared.css` | 上記画面の共通レイアウトと装飾 | `game-screens.json`から参照して読む |
| `asset-folders.txt` | 素材フォルダーの分類と命名規約 | 説明用。実行設定ではない |
| `story-adaptation.md` | 作品固有の翻案・人物・シナリオ方針 | 説明用。実行設定ではない |

画面HTML/CSSはJSON内へ埋め込まず、`screens/`内の独立ファイルに書きます。画面全体の背景は`game-screens.json`、画面内部の部品の配置と見た目はHTML/CSS、会話中のUIは`player-ui.json`が担当します。

### 旧画面形式との互換性

HTMLテンプレートがある画面では、HTML/CSSから実際の表示要素とボタン動作を作ります。生成される`items`や配置情報はパッケージ・再生用のデータであり、設定JSONへ重複保存しません。テンプレートのない旧形式画面では、互換性のためJSONの`items`がボタン定義として使われます。

素材参照は作品の`asset/`を基準にした相対パスで記述します。画面から使う画像も同様です。コンパイラの生成物とビルド成果物は`.novel/`に置かれるため、手編集しないでください。
